# Branching and committing

When authoring work in this repo:

- Create a new feature branch
- Make your commit(s) to this branch
- Push the branch to GitHub
- When ready to merge your work, open a pull request
- [Automatic checks](../processes/CI-CD.md#on-pull-requests) will run against the repo
- This pull request must be approved by at least one of your teammates
  - One dev's work specifically needs to be tested by the other
- If approved, your work will be [merged to main and deployed](../processes/CI-CD.md#on-merge-to-main)

After your work is merged, you should delete your feature branch.
When starting more work, repeat this process.

**Note:** this strategy is based on [GitHub Flow](https://docs.github.com/en/get-started/using-github/github-flow).
