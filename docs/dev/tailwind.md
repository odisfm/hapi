# Tailwind

## Utility classes

The following custom utility classes are available:

### RMIT Colours

`r-red` — RMIT red, should not be tinted

`r-blue` or `r-blue-950` — RMIT blue

`r-blue-700`, `r-blue-500`, `r-blue-300` — various approved tints of RMIT blue

`r-yellow-500`, `r-yellow-400`, `r-yellow-300` — various approved tints of RMIT yellow

These can be used [wherever standard Tailwind colours can](https://tailwindcss.com/docs/colors), e.g. `bg-r-red` or `border-r-blue-500`.

### RMIT Typefaces

#### Fonts

`font-headline` — Museo, used only in headlines

`font-copy` — Helvetica Neue LT Pro, used everywhere else

#### Weights

Above fonts available in weights `300`, `500`, `700`, using classes `font-light`, `font-regular`, `font-bold` respectively.
