# Capstone project documents

These are the documents from the RMIT capstone project (2026) that built
the first version of the HAPI Showcase. They're kept for reference: they
record what HAPI asked for, what was agreed and how it was tested.

**They describe the project as it was planned and delivered, not the
current system.** Some details have changed since, for example:

- the staging environment
- Supabase as the hosted database
- GitHub as the deploy source

For how things work now, start from the [main README](../../README.md).

| Document | What it is |
|---|---|
| [requirements-specification.md](requirements-specification.md) | Functional and non-functional requirements, final version (v9.0), including descoped and stretch goals |
| [testing-scenarios-ua.md](testing-scenarios-ua.md) | User acceptance test scenarios |
| [testing-scenarios-ua-phase2.md](testing-scenarios-ua-phase2.md) | User acceptance test scenarios, phase 2 |
| [solution-design.md](solution-design.md) | The original proposal for the front end, back end and data layer |

In these documents, "the client" means HAPI.
