# Tailwind

## Utility classes

The following custom utility classes are available:

### RMIT Colours

`r-red` — RMIT red, should not be tinted

`r-blue` or `r-blue-950` — RMIT blue

`r-blue-700`, `r-blue-500`, `r-blue-300` — various approved tints of RMIT blue

These can be used [wherever standard Tailwind colours can](https://tailwindcss.com/docs/colors), e.g. `bg-r-red` or `border-r-blue-500`.
